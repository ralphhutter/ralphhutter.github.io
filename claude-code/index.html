Einrichten von Claude Code

Vier Schritte vor dem Seminar: Laptop, Claude-Pro-Abo und GitHub-Konto, Claude Code installieren, zwei Editoren.

Version 0.2.0 Stand 14.11.2026 Claude Code für Einsteiger 25./26.11.2026 Ralph Hutter

Übersicht

Vier Dinge, ca. 30 Minuten

Die Vorbereitung ist bis spätestens Dienstag, 24.11.2026 zu erledigen. Das Seminar startet am ersten Morgen direkt mit Claude Code.

Reihenfolge zwingend

Zuerst das Claude-Pro-Abo, danach Claude Code installieren. Die Anmeldung in Claude Code funktioniert nur mit einem bezahlten Konto.

1 Laptop

Privater Mac oder Windows-Laptop mit Installationsrechten.

2 Konten

Claude Pro (USD 20 pro Monat) und ein kostenloses GitHub-Konto.

3 Claude Code

Mit einem Befehl im Terminal installieren und anmelden.

4 Editoren

Obsidian und Visual Studio Code installieren, beide kostenlos.

Schritt 1

Laptop bereitstellen

Ins Seminar gehört ein privater Laptop mit macOS 13 oder neuer oder Windows 10 (Version 1809) oder neuer. Auf Firmengeräten sind Installationen und das Terminal häufig gesperrt, und Internetdienste können blockiert sein.

Nicht geeignet

Tablets wie das iPad und Chromebooks.

Schritt 2

Konten anlegen

Claude Pro

Claude Code ist im kostenlosen Claude-Konto nicht enthalten. Es braucht mindestens Claude Pro.

  1. claude.ai öffnen und anmelden oder ein Konto erstellen.
  2. Upgrade wählen und das Abo Pro mit monatlicher Zahlung abschliessen (USD 20 pro Monat, monatlich kündbar). Das Jahresabo lohnt sich für das Seminar nicht.
  3. Das Abo frühestens eine Woche vor dem Seminar abschliessen.

Wer bereits Claude Pro, Max oder ein Team-Konto nutzt, kann diesen Teil überspringen.

Optional: Zusatzguthaben

Das Pro-Abo hat ein Nutzungskontingent. Zwei intensive Seminartage können es ausschöpfen, danach heisst es einige Stunden warten. Wer ohne Unterbruch weiterarbeiten will, kann in den Einstellungen von claude.ai Zusatzguthaben (Usage Credits) kaufen. Für das Seminar genügen einmalig rund USD 20. Der Kauf ist freiwillig und nur nötig, wenn das Kontingent im Seminar ausgeht.

GitHub

Am zweiten Tag geht eine eigene Web-App online. Dafür braucht es ein kostenloses GitHub-Konto.

  1. Auf github.com/signup ein Konto erstellen.
  2. Die E-Mail-Adresse über die Mail von GitHub bestätigen.

Wer bereits ein GitHub-Konto hat, kann es verwenden.

Schritt 3

Claude Code installieren

Claude Code läuft im Terminal, einem Fenster, in das Befehle als Text eingegeben werden. Die Installation ist ein einziger Befehl und braucht keine Administratorrechte.

Mac
  1. Terminal öffnen: cmd + Leertaste, «Terminal» tippen, Enter.
  2. Diesen Befehl ins Terminal kopieren und mit Enter ausführen: 
    curl -fsSL https://claude.ai/install.sh | bash
  3. Warten, bis die Eingabezeile wieder erscheint. Die Installation zeigt keinen Fortschritt an.
  4. Terminal schliessen und neu öffnen.
Windows
  1. Zuerst Git for Windows installieren. Die Standardeinstellungen im Assistenten passen.
  2. PowerShell öffnen: Startmenü, «PowerShell» tippen, Enter. Die Eingabezeile beginnt mit PS C:\.
  3. Diesen Befehl in PowerShell kopieren und mit Enter ausführen: 
    irm https://claude.ai/install.ps1 | iex
  4. Warten, bis die Eingabezeile wieder erscheint. PowerShell schliessen und neu öffnen.

Installation prüfen

Im neuen Terminalfenster eingeben:

claude --version

Erscheint eine Versionsnummer, zum Beispiel 2.1.211 (Claude Code), ist die Installation gelungen.

Anmelden

  1. claude eingeben und mit Enter starten.
  2. Ein Farbschema wählen, danach die Anmeldung mit dem Claude-Konto (Pro).
  3. Der Browser öffnet sich. Mit dem Konto aus Schritt 2 anmelden und den Zugriff bestätigen.
  4. Zurück im Terminal die Fragen zur Sicherheit und zum Ordner bestätigen.
  5. Als ersten Test Hallo, was kannst du? eingeben und mit Enter senden. Antwortet Claude, ist alles bereit.
  6. Claude Code mit /exit beenden.

Schritt 4

Editoren installieren

Beide Programme sind kostenlos. Eine Einrichtung ist nicht nötig, sie folgt gemeinsam im Seminar.

Obsidian

Editor für das Personal OS. Von obsidian.md installieren, einmal starten, schliessen.

Visual Studio Code

Editor für die Web-App am zweiten Tag. Von code.visualstudio.com installieren, einmal starten, schliessen.

Kurztest

Vor dem Seminar alles einmal prüfen

  • claude --version zeigt eine Versionsnummer.
  • claude startet ohne neue Anmeldung und antwortet auf eine Frage.
  • Obsidian und Visual Studio Code starten.
  • Die Zugangsdaten zu Claude und GitHub sind zur Hand.
Fertig

Damit ist alles bereit, um am ersten Seminartag direkt mit Claude Code zu starten.

Hilfe

Wenn etwas nicht klappt

  • claude wird nicht gefunden (Mac: «command not found», Windows: «not recognized»): Terminal schliessen und neu öffnen. Hilft das nicht, claude doctor ausführen oder die Hilfe von Anthropic lesen.
  • Windows: «The token '&&' is not a valid statement separator» oder «'irm' is not recognized»: Der Befehl wurde im falschen Fenster eingegeben. Er gehört in PowerShell, nicht in die Eingabeaufforderung (CMD).
  • Anmeldung schlägt fehl oder Claude Code verlangt ein Abo: Das Konto hat kein Pro-Abo. Auf claude.ai unter Einstellungen den Plan prüfen.
  • Etwas anderes: Meldung an ralph.hutter@fh-hwz.ch. Den Laptop auf jeden Fall mitbringen, der Rest lässt sich am Morgen vor Beginn lösen.
