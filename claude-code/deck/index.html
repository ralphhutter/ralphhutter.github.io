Tag 1 · Modul 2

Sicherheit: Checkpoints und Berechtigungsmodi

ModusVerhalten
DefaultFragt vor Dateiänderungen und Befehlen
Auto-accept editsÄndert Dateien ohne Rückfrage, fragt bei anderen Befehlen
Plan ModeErkundet und schlägt einen Plan vor, ändert nichts
AutoAutomatische Sicherheitschecks, Research Preview

Wechseln mit Shift+Tab.

Checkpoints

Vor jeder Dateiänderung entsteht ein Snapshot. Zweimal Esc springt zurück.

Grenze

Aktionen in externen Systemen, etwa Datenbanken, APIs oder Deployments, lassen sich nicht per Checkpoint rückgängig machen.

Steuern

Esc stoppt sofort. Eine Korrektur eintippen und Enter: Claude liest sie nach dem aktuellen Schritt.

Tag 1 · Modul 5

Markdown: die Arbeitssprache zwischen Mensch und KI

  • Leichtgewichtige Auszeichnungssprache, 2004 von John Gruber und Aaron Swartz entwickelt
  • Reiner Klartext mit Endung .md, lesbar in jedem Editor
  • Claude antwortet in Markdown, man bearbeitet Markdown, schickt es zurück: keine Formatkonvertierung
  • Arbeitsformat Markdown, DOCX und PDF nur noch für die formelle Auslieferung

Achtung

In E-Mail-Clients oder Word ohne Plugin erscheinen die Zeichen roh. Per Prompt steuern.

Tag 1 · Modul 6

Warum ein lokaler Ordner als Basis

Claude Code kann das

Read ~/PersonalOS/Projects/website-relaunch/notes.md

Claude Code kann das nicht

Fetch https://www.notion.so/my-workspace/notes-abc123
  • Notion, Google Docs oder Confluence sind für Claude Code nicht direkt lesbar
  • Lokale Markdown-Dateien: suchen, anlegen, bearbeiten, quer verarbeiten
  • Externe Dienste später gezielt über MCP anbinden

Ablage

PersonalOS nicht in einem Cloud-Only-Ordner von iCloud, OneDrive oder Dropbox ablegen.

MCP: der Standard für externe Verbindungen

Model Context Protocol, offenes Protokoll, von Anthropic im November 2024 veröffentlicht.

  • MCP-Client: die Anwendung, im Kurs Claude Code
  • MCP-Server: stellt einen Dienst über Tools bereit
  • stdio: Server läuft lokal als Prozess
  • HTTP/SSE: Server läuft remote, über eine URL erreichbar
TypBeispiel
ToolsNachricht senden, Datei lesen
ResourcesDokumente, Datenbankeinträge
PromptsStandardisierte Abläufe

3 · Wird er gepflegt?

Letzter Commit, Umgang mit Issues

4 · Quellcode einsehbar?

Für sensible Systeme ist Open Source Mindeststandard

Bezugsquellen: github.com/modelcontextprotocol/servers, mcpservers.org, Hersteller, Community.
